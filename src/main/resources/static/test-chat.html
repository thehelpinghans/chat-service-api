1. 연결 관리

테넌트/구매자가 완전히 독립된 WS 연결(각자 다른 토큰으로 별도 STOMP CONNECT) — 0번 완료 시 둘 다 자동으로 붙고, 채팅방이 여러 개 있을 수 있어 다른 방으로 전환하고 싶을 때 수동으로 다시 누를 수 있게 버튼은 남겨둠.

테넌트: 연결 안됨
구매자: 연결 안됨

2. 채팅방 (테넌트 / 구매자 화면 분리)

같은 채팅방을 양쪽 화면에서 동시에 봄 — 왼쪽은 판매자(테넌트), 오른쪽은 구매자. 연결 시 최신 메시지를 자동 조회하고, PAYMENT_REQUEST 메시지의 결제 버튼은 구매자 쪽에만 표시됩니다.
